~2% dari profit, hilang di setiap mint baru, selamanya. Bukan efek samping kosmetik.

YANG DIMINTA:

     kirim closeAccount untuk ATA token pasangan itu — pakai token program yang benar

     jangan hardcode Tokenkeg…).
  2. Idempoten: kalau account-nya sudah nggak ada, perlakukan sebagai SUKSES
     ("account not found" bukan error).
  3. Best effort dan tidak boleh melempar: dari titik close sudah confirmed, tidak ada
     yang boleh mengubah position tertutup jadi throw. Gagal → catat + log, jangan page
     operator untuk $0.19 (ini beda dari sweep: sweep gagal = value nyangkut di memecoin,
     harus page; ATA gagal = $0.19, cukup log).
  4. Rekam signature-nya. Tambah kolom (mis. `ata_close_signature`) — JANGAN timpa
     `sweep_signature` (itu bukti jual tokennya, harus tetap utuh).
  5. Pasang di DUA jalur yang membuat ATA kosong, bukan satu:
     (a) `closeLivePosition` setelah `sweepResidualPairedToken` (liveExecution.ts:1993), dan
     (b) jalur auto-unwind gagal-open / rescue (lihat `rescueSignature` di liveExecution.ts
         ~baris 125-179) — di sana token juga dijual balik ke SOL dan ATA-nya ditinggal.
  6. Tambah test: ATA ditutup saat sweep settled; ATA TIDAK ditutup saat sweep failed/
     unmeasured (value masih di token — menutup ATA-nya justru mustahil/berbahaya);
     "account not found" = sukses; kegagalan closeAccount tidak menggagalkan close.
